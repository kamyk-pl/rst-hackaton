# #03 — Szkielet layoutu + sidebar per rola

## What to build

Zbudować wspólny layout aplikacji z bocznym panelem nawigacyjnym (sidebar), gdzie linki różnią się w zależności od roli zalogowanego użytkownika.

## Acceptance criteria

- [ ] Wspólny layout z sidebarem renderowany dla wszystkich zalogowanych użytkowników
- [ ] Sidebar pacjenta zawiera: Mój profil, Dokumentacja, Umów wizytę, Historia wizyt
- [ ] Sidebar lekarza zawiera: Mój profil, Moje terminy, Harmonogram wizyt
- [ ] Aktywna sekcja jest wyróżniona w sidebarze
- [ ] Przycisk wylogowania w sidebarze
- [ ] Layout responsywny (działa na desktopie)
