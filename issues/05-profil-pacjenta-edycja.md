# #05 — Edycja profilu pacjenta

## What to build

Formularz edycji profilu pacjenta umożliwiający uzupełnienie i aktualizację danych zdrowotnych.

## Acceptance criteria

- [ ] Strona `/pacjent/profil/edytuj` z formularzem
- [ ] Pola: imię, nazwisko, data urodzenia, alergie (textarea), choroby przewlekłe (textarea), leki stałe (textarea)
- [ ] Formularz pre-wypełniony aktualnymi danymi
- [ ] Po zapisaniu — przekierowanie na `/pacjent/profil` z komunikatem sukcesu
- [ ] Walidacja: imię i nazwisko wymagane
