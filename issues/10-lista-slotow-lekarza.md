# #10 — Lista slotów lekarza

## What to build

Widok listy wszystkich slotów lekarza z informacją o ich statusie.

## Acceptance criteria

- [ ] Lista slotów na stronie `/lekarz/terminy`
- [ ] Każdy slot pokazuje: datę, godzinę, status (DOSTĘPNY / ZAREZERWOWANY)
- [ ] Sloty posortowane chronologicznie
- [ ] Gdy brak slotów — komunikat zachęcający do dodania
- [ ] Dostęp tylko dla zalogowanego lekarza
