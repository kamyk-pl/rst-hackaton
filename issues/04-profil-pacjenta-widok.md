# #04 — Wyświetlanie profilu pacjenta

## What to build

Strona profilu pacjenta wyświetlająca jego dane zdrowotne w trybie read-only.

## Acceptance criteria

- [ ] Strona `/pacjent/profil` dostępna tylko dla zalogowanego pacjenta
- [ ] Wyświetla: imię, nazwisko, datę urodzenia, alergie, choroby przewlekłe, leki stałe
- [ ] Gdy profil nie był jeszcze wypełniony — wyświetla stosowny komunikat / puste pola
- [ ] Link do edycji profilu
