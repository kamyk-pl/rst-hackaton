# #07 — Lista i usuwanie dokumentów

## What to build

Widok listy wszystkich dokumentów medycznych pacjenta z możliwością usunięcia i pobrania.

## Acceptance criteria

- [ ] Lista dokumentów na stronie `/pacjent/dokumenty`
- [ ] Każdy dokument pokazuje: nazwę pliku, typ, datę uploadu
- [ ] Możliwość pobrania/otwarcia dokumentu
- [ ] Możliwość usunięcia dokumentu (usuwa plik z filesystemu i rekord z bazy)
- [ ] Gdy brak dokumentów — komunikat zachęcający do uploadu
- [ ] Dostęp tylko dla właściciela dokumentów
