# #20 — Internacjonalizacja (i18n)

## What to build

Wyekstrahować wszystkie polskie stringi z komponentów UI do pliku tłumaczeń, umożliwiając łatwą zmianę języka interfejsu w przyszłości. Na potrzeby prototypu wystarczy jeden język (PL), ale kod powinien być przygotowany na rozszerzenie.

## Acceptance criteria

- [ ] Zainstalowana biblioteka i18n (np. `next-intl` lub prosty własny mechanizm)
- [ ] Plik `src/locales/pl.ts` zawiera wszystkie stringi UI (etykiety, komunikaty błędów, placeholder'y, nazwy sekcji)
- [ ] Komponenty używają kluczy tłumaczeń zamiast hardkodowanych polskich stringów
- [ ] Komunikaty błędów z server actions również przekazywane przez i18n
- [ ] Zmiana języka możliwa przez zmianę jednego pliku konfiguracyjnego

## Blocked by

None — can start immediately
