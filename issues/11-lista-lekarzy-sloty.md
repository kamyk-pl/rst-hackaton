# #11 — Lista lekarzy z dostępnymi slotami

## What to build

Widok dla pacjenta umożliwiający przeglądanie lekarzy z wolnymi terminami i wybór konkretnego slotu.

## Acceptance criteria

- [ ] Strona `/pacjent/umow-wizyte` pokazuje listę lekarzy którzy mają min. 1 dostępny slot
- [ ] Każdy lekarz pokazuje: imię, nazwisko, specjalizację
- [ ] Po kliknięciu lekarza — widać jego dostępne sloty (data, godzina)
- [ ] Sloty posortowane chronologicznie
- [ ] Lekarze bez dostępnych slotów nie są widoczni
- [ ] Dostęp tylko dla zalogowanego pacjenta
