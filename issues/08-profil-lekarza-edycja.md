# #08 — Edycja profilu lekarza

## What to build

Strona profilu lekarza z możliwością wyświetlenia i edycji danych.

## Acceptance criteria

- [ ] Strona `/lekarz/profil` wyświetla: imię, nazwisko, specjalizację
- [ ] Formularz edycji z polami: imię, nazwisko, specjalizacja
- [ ] Formularz pre-wypełniony aktualnymi danymi
- [ ] Po zapisaniu — komunikat sukcesu
- [ ] Walidacja: wszystkie pola wymagane
- [ ] Dostęp tylko dla zalogowanego lekarza
