# #13 — Historia wizyt pacjenta

## What to build

Widok listy wszystkich wizyt pacjenta (zaplanowanych i zakończonych).

## Acceptance criteria

- [ ] Strona `/pacjent/wizyty` pokazuje listę wizyt pacjenta
- [ ] Każda wizyta pokazuje: lekarza (imię, nazwisko, specjalizacja), datę i godzinę, status (ZAPLANOWANA / ZAKOŃCZONA)
- [ ] Wizyty posortowane chronologicznie (najnowsze pierwsze)
- [ ] Wizyty ZAKOŃCZONA mają link do szczegółów/podsumowania
- [ ] Gdy brak wizyt — stosowny komunikat
- [ ] Dostęp tylko dla zalogowanego pacjenta
